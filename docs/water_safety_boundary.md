# Water-safety boundary

This repository is for independent research, education, and synthetic planning support only.

It is not:

- public-health advice
- drinking-water safety certification
- emergency-response software
- SCADA or utility-control software
- regulatory reporting software
- a replacement for water utility engineers, certified laboratories, regulators, or public-health authorities

Real water-system decisions require verified field instrumentation, certified sampling, laboratory testing, expert review, hydraulic-model validation, public-health authority, chain-of-custody, legal governance, and clear uncertainty communication.
